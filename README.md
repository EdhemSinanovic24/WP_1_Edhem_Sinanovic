WP_1_Edhem_Sinanovic - IPI Akademija Web Projekat

Opis projekta
Web stranica IPI Akademije izrađena u sklopu predmeta Web Programiranje 2025/2026.
Stranica sadrži informacije o kursevima, rasporedu, kontakt formu i Student Fun Zone sekciju.

Tehnologije
- HTML5
- CSS3
- JavaScript (Vanilla)

Struktura projekta

```
WP_1_Edhem_Sinanovic/
├── index.html              - Početna stranica
├── style.css               - Globalni stilovi
├── javascript.js           - Glavna JavaScript logika
├── kontakt.html            - Kontakt stranica sa formom
├── popis.html              - Popis dostupnih kurseva
├── raspored.html           - Raspored kurseva
├── slike/                  - Grafički resursi
├── whiteboard/             - Interaktivni Whiteboard
├── visionboard/            - Studentski Vision Board
├── kanban/                 - Mini Kanban Ploča
├── Bingo/                  - IT Bingo Kviz
└── Kviz/                   - Studentski IT Kviz
```

Stranice
- O kursevima - Početna stranica sa opisom IPI Akademije
- Popis kurseva - Lista dostupnih obrazovnih programa
- Raspored kurseva - Aktuelni raspored nastave
- Kontakt - Kontakt forma i adresa akademije

Student Fun Zone
Interaktivni sadržaj za studente:
- Interaktivni Whiteboard - Digitalna tabla za crtanje
- Visual Board - Vision board za ciljeve i motivaciju
- Kanban Board - Organizacija zadataka sa drag & drop
- Bingo - IT Bingo Kviz sa pitanjima iz programiranja
- Kviz - IT kviz sa 5 pitanja

Funkcionalnosti
- Responzivni dizajn sa sidebar navigacijom
- Top header traka sa logom
- Kontakt forma sa mailto metodom
- Kanban ploča sa PDF i PNG izvozom
- Slanje Kanban izvještaja mailom
- Bingo igra sa IT pojmovima
- Kviz sa trenutnim rezultatima

Pokretanje projekta
ne zahtijeva server - dovoljno je otvoriti index.html u browseru.
